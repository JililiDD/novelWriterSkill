# 《雪尽刀还》后期章节生成经验（第八至十章）

适用：生成悬疑旧案/武侠终局章节时，尤其是信息密集的后期揭秘、终章回收与 Dashboard 验证。

## 后期章节合同与节奏

### 第八章《官卷无名》
- 功能：把江湖旧案压向官卷/朝廷定性系统。
- 核心合同：陆青崖提供旧官库路径；官卷死者十六人与雪夜账“北炉十七口”冲突；被撤换验尸记录证明软筋散；官卷与武盟案卷同一份底稿；缇骑围杀；慧尘重伤救人。
- 硬边界：只放大“第十七人”、软筋散来源、官卷底稿来源，不揭最终身份。

### 第九章《顾舟沉处》
- 功能：集中揭示但不终局清算。
- 核心合同：顾沉舟现身并承认主持定论/盖印；交出雪夜账最后一页与密信；“无面客”升级为朝廷暗线；三庄代理方向成立；第十七人=沈家旧仆之子陈栓，被迫打开内门后被伪装抹去；柳照水短笺真相阶段性回收。
- 硬边界：顾沉舟有罪但非最终首恶，不能洗白；无面客真实身份、三庄具体代理、影刀身份留给终章；柳照水说明任务但不倾倒听雨楼全部真相。

### 第十章《雪尽刀还》预飞
- 功能：终局回到沈家刀庐，完成旧案三层结构和主题闭环。
- 核心合同：三庄代理/朝廷暗线回收；影刀现身；柳照水对摘星楼残余；陆青崖牵制武盟追兵并成为事实见证；慧尘护证；顾沉舟公开旧案并承担罪责；沈照击败影刀但不私刑杀尽，最后斩断假冒沈家刀的兵刃；证据流入江湖与朝堂；雪停刀归鞘。
- 终章主题：雪尽=真相出白；刀还=沈家刀法归于本心，不再被仇恨与阴谋借用。

## 后期章节常见坑

1. **语义满足但精确合同词缺失**
   - 第九章生成后语义上已写“旧渡”“十七口”“内门一口”，但自动复检缺少精确词形“江上旧渡”“第十七人”“沈家内门”。
   - 处理方式：做最小确定性补丁，同时修改 final 与 draft；不要重写整章。
   - 示例补丁思路：
     - “顾家旧渡在江弯处。” → “顾家旧渡在江弯处，也是旧账里被刮去的江上旧渡。”
     - “沈照盯着‘内门一口’四字。” → 加一句“那不是旁枝，是沈家内门。”
     - “十七口不是沈家名册的十七人。” → 改为“所以第十七人不在沈家名册里……”

2. **终局信息倾倒风险**
   - 后期揭秘章不能变成说明书；必须通过物证、逼问、沉默、代价、对决推进。
   - 顾沉舟、三庄代理、无面客相关台词尤其容易过长。让证据说话，让人物只承认他们能知道/必须承认的部分。

3. **复杂反派洗白风险**
   - “非最终首恶”不等于无罪。
   - 顾沉舟可以被迫、可以自辩、可以交证据，但必须明确承担“事后定性者”罪责。

4. **终章爽文化风险**
   - 不要写成一刀杀尽后天下太平。
   - 旧案可以得白，世道仍有余波。沈照的成长是辨明罪责、留下证据，而不是滥杀。

5. **角色知识边界**
   - 柳照水：能用医理/毒理/听雨楼旧法补位，不能全知开挂。
   - 陆青崖：可选择事实与证据，但不要突然成为沈照下属。
   - 慧尘：用行动赎罪，不能全知解释。
   - 影刀：是污名化沈家刀法的工具/对照，不应升级为真正幕后主谋。

## 推荐复检脚本片段

使用 Python pathlib，避免依赖环境中可能缺失的 `cat/head/git`：

```bash
python3 - <<'PY'
from pathlib import Path
import re
root=Path('/home/ddxy/Desktop/hermes/jobs/novel-generator/xuejin-daohuan')
ch='09'
final=root/f'chapters/ch{ch}_final.md'
draft=root/f'scenes/ch{ch}_s01_draft.md'
audit=root/f'audits/ch{ch}_lore_audit.md'
for label,p in [('FINAL',final),('DRAFT',draft),('AUDIT',audit)]:
    print(label, p.exists(), p.stat().st_size if p.exists() else 0)
text=final.read_text(encoding='utf-8')
forbidden=['F-','[伏笔]','agent','audit','outline','scene','场景一','上一章','本章','前文','伏笔','读者','作者']
print('FORBIDDEN_FOUND', [w for w in forbidden if w in text])
required=['江上旧渡','顾沉舟','雪夜账最后一页','密信','无面客','三庄','第十七人']
print('REQUIRED_MISSING', [w for w in required if w not in text])
print('CHARS_NO_WS', len(re.sub(r'\s+','', text)))
PY
```

# Element Library — 小说元素库

Built-in reusable trope/element options. Elements should be divided into core and secondary. Too many core elements cause drift.

## 身份 / 开局元素

- 穿越：角色进入异世界/异时代/异身份。
- 重生：带着前世记忆重来。
- 夺舍：身体/身份被替换，需处理伦理和身份风险。
- 失忆：知识缺口驱动悬疑或关系。
- 替身：身份伪装、替嫁、替死、替职。
- 退婚：关系冲突开局，常见爽文/言情。
- 废柴开局：能力低谷，适合升级。
- 天才陨落：过去强、现在失去能力或地位。
- 隐藏身份：身份差异制造张力。
- 遗孤：旧案、复仇、身世驱动。
- 退休高手：低调强者卷入新局。
- 反派觉醒：反派意识到命运/剧本并自救。
- 炮灰自救：小人物知道危险叙事后改命。

## 金手指 / 机制元素

- 系统流：外部规则/任务/奖励机制。
- 面板流：数值化能力与状态。
- 签到流：周期奖励。
- 模拟器流：通过模拟未来获得信息/奖励。
- 熟练度流：练习积累可见成长。
- 加点流：资源分配改变能力。
- 经营面板：资源、建筑、人口、贸易等经营机制。
- 空间流：随身空间、仓储、种田、避难。
- AI辅助：AI作为工具/伙伴/监控/对手。
- 预知梦：不稳定未来线索。
- 时间循环：重复时间带来规则博弈。
- 存档读档：风险回滚，但需限制代价。
- 无限流副本：多个规则场景与任务。

## 扩展网文机制元素

- 反向系统流：系统不是帮助主角，而是限制、监控、误导或压迫主角；主角通过理解和绕过规则成长。风险：规则不能随便改，主角不能靠作者强行钻漏洞。
- 苟道流：主角低调、避险、积累，尽量不暴露实力。风险：不能苟到没有剧情，外部压力必须逼迫选择。
- 迪化流：配角过度脑补主角深不可测，误会推动剧情。风险：不能所有人降智，误会要逐步升级。
- 诸天流：主角穿梭多个世界/副本/位面获取资源或完成任务。风险：主世界主线不能丢。
- 万界聊天群：多世界角色通过群聊互动、交易、任务。风险：群员不能只是弹幕，交易规则要限制资源膨胀。
- 规则怪谈：角色在规则中生存，规则可能矛盾、污染或隐藏条件。风险：规则要可推理，不能随意新增规则救场。
- 副本直播流：副本挑战与外部观众/弹幕/平台机制结合。风险：弹幕不能抢戏，外部评价要服务压力或信息差。
- 御兽流：人与兽/灵宠/召唤物共同成长。风险：御兽不能只是技能包，需要关系、生态、成长机制。
- 领主流：经营领地、人口、资源、军事、外交。风险：资源生产和消耗要有逻辑。
- 宗门经营：经营门派、弟子、资源、声望、传承。风险：弟子不能只是数字，外部压力要持续。
- 基建流：从无到有建设聚落、城市、基地或文明设施。风险：资源、人力、技术限制要存在。
- 美食经营：靠食物、店铺、人情、经营推动剧情。风险：食物描写不能只是形容词堆叠，经营要有压力。
- 囤货流：提前储备资源应对末世、灾难、穿越等。风险：储备空间/资金/物流要合理，不能无限囤导致无危机。
- 末世重生：角色带记忆回到灾难前，提前布局。风险：预知不能解决所有问题，蝴蝶效应要出现。

## 情感 / 关系元素

- 真假千金 / 真假少爷：身份错位、家庭偏爱、阶层落差。风险：不要所有家人无脑偏心，身份揭露后要有社会/情感后果。
- 追妻火葬场：一方错失/伤害后追悔，关系重建或无法重建。风险：不能轻易原谅，伤害必须有代价。
- 破镜重圆：旧关系破裂后重逢修复。风险：破裂原因要真实，不能靠一句误会解除。
- 强强：双方都有能力、目标和边界，不是一方附庸。风险：不能让其中一方变工具人。
- 群像权谋：多角色、多阵营、多利益线共同推动。风险：需要篇幅，每条线要有清晰目标。
- 全员恶人：主要角色都有灰度、私心或罪责。风险：不能全员变态化，读者仍需理解人物逻辑。

## 悬疑 / 恐怖 / 设定元素

- 社会派悬疑：案件背后是社会结构、制度、阶层或时代问题。风险：不能只靠口号批判，案件本身仍需成立。
- 密室 / 不可能犯罪：案件看似物理上不可能。风险：解法必须公平，不要靠超自然硬解，除非一开始说明类型。
- 民俗禁忌：村规、祖训、祭祀、祠堂、山神、水鬼、族谱等。风险：禁忌要有代价，民俗元素不能只当装饰。
- 认知污染：角色知道/看见/理解某事后被改变。风险：污染规则要稳定，不能用“疯了”代替逻辑。
- 叙述诡计：文本视角、时间、身份、记忆或叙述者可靠性构成谜题。风险：需要强设计，不能靠隐藏关键信息欺骗读者。

## 经营 / 成长 / 组织元素

- 学院流：学校/学院/宗门课堂作为成长场域。风险：课程、竞争、考试要推动主线。
- 小队冒险：固定小队共同探索/战斗/成长。风险：每个队员要有功能和弧光。
- 组织养成：主角建立或改造组织。风险：组织成员要有利益和矛盾，不要自动忠诚。
- 文明重建：灾后/异界/星际环境中重建秩序。风险：资源、制度、信任、暴力都要处理。
- 技术种田：靠技术扩散改变生产方式。风险：技术落地要考虑材料、工艺、人员、社会阻力。

## Compatibility notes

- `系统流 + 悬疑推理`: system must not reveal answers unfairly.
- `文学向 + 强面板`: weaken UI or embed it diegetically.
- `短篇 + 高燃史诗 + 群像`: likely too large.
- `恐怖 + 高频吐槽`: becomes horror-comedy; confirm tone.
- `穿越 + 半文半白`: adapt modern mechanisms into in-world forms if needed.

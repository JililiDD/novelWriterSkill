# Layered Novel Planning — 全书骨架 + 分卷精规划

Use this when a long novel (roughly 15万字+) has many stages, teams, factions, cases, tournaments, or changing casts.

## Core principle

Do **not** over-plan every later-stage character, team, faction, transfer, match, or chapter before prose begins. Lock the full-book spine, then plan the current volume in detail. After finishing or substantially drafting that volume, refine the next volume using what emerged naturally.

This avoids:
- setup bloat before chapter 1
- rigid future outlines that ignore character chemistry
- unused character/team lists
- forcing later arcs to obey stale early guesses

## Three planning layers

### 1. Full-book spine — lock early

Always define and confirm:
- title / genre / target length / chapter scale
- main character growth line
- core theme and reader promise
- volume-level structure
- final-stage target or book-ending promise
- forbidden elements and tone boundaries
- basic world/system rules that cannot drift
- a small set of full-book anchor characters/factions

This level prevents the project from drifting.

### 2. Current-volume bible — plan in detail

Before writing a volume, detail only the material needed for that volume:
- volume chapter count and arc
- local cast and relationship changes
- key locations / institutions / teams / factions
- local antagonists or rivals
- major set pieces / matches / cases / battles
- volume-specific rules, clues, foreshadowing, and exit conditions
- which characters continue, pause, exit, or become future callbacks

For a sports/esports story, this means fully planning the current tournament/league stage and relevant teams, but only using placeholder-level planning for future professional leagues or transfer markets until those arcs approach.

### 3. Rolling expansion — update between volumes

After drafting a volume:
- review which characters had strong chemistry
- identify which planned items were unused or changed
- promote only useful side characters to long-term canon
- refine the next volume’s teams/factions/characters
- update System Bible and continuity ledgers with confirmed facts

Do not treat early brainstorming as permanent canon unless the user confirmed it into the System Bible or volume bible.

## Character and faction scale guidance

For a ~20–30万字 novel:
- full-book core cast: usually 8–12 characters
- important supporting cast across all volumes: often 15–25 characters
- functional characters can be created per chapter/volume and tracked locally

Only full-book core cast and confirmed recurring supporting cast need full Character Bible entries early. Functional characters can be recorded in chapter briefs or volume notes until promoted.

## Esports/team-planning guidance

Use three tiers:

1. **Full-book anchor teams** — define early at concept level:
   - protagonist starting team/school
   - main rival school/team
   - training/academy organization
   - eventual professional-stage team

2. **Volume-level teams** — define when the volume starts:
   - full roster only if they affect plot or matches
   - playstyle, strengths, weaknesses, and narrative function
   - which members matter beyond one match

3. **Functional opponent teams** — create on demand:
   - used to demonstrate one tactic, pressure, or growth beat
   - no full bible unless they recur

## Confirmation rule

When the user asks whether to plan everything now or plan by volume, recommend this layered approach unless the user explicitly wants a fully locked long outline.

Before chapter generation, the current volume must still have enough detail for preflight and continuity audit.

# New Character / Location Provenance — Compatibility Reference

This former standalone gate is retained only for backward compatibility.

Use `continuity-bug-audit.md`, section **Provenance for new named entities**, as the canonical rule for introducing characters, factions, artifacts, abilities, organizations, institutions, and locations.

Use `chapter-pipeline.md` to place relevant provenance requirements in the approved chapter contract and Context Manifest.

Do not maintain a separate provenance procedure here.
